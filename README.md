# 潮汐桌游社 · 在线桌游

在线桌游集合，目前包含《新岸宪章：群岛拓荒》《星晶商路》和2–4人原创地产经营游戏《海湾地产局》。游戏共用房间号邀请与 WebSocket 房间服务。

## 星晶商路

- 双人规则：每种普通晶石公共储备4枚、万能星砂5枚；每级市场始终翻开4张卡，牌堆为40/30/20张；随机展示3位赞助人。
- 每回合只能做一项行动：拿取晶石、购买发展卡、预留发展卡并取得星砂（若仍有），或盲抽并预留牌堆顶卡。
- 通常拿3种不同颜色；若公共储备里不足3种可拿，则可以少拿1至2种。也可以拿2枚同色，但该色储备行动前至少要有4枚。
- 三个等级的市场牌各有独立牌堆。发展卡提供永久颜色折扣和声望；预留卡最多3张，不能弃掉，只能购买。
- 回合结束时若持有超过10枚筹码，由玩家选择退回超额部分；之后检查赞助人，满足多人条件时本回合任选其一。赞助人提供3点声望。
- 达到15声望触发终局，补齐本轮使双方行动次数相同。声望高者获胜；平分时发展卡较少者获胜；再平则共享胜利。
- 卡牌、名称与视觉均为本项目原创生成内容，不复用其他桌游的插画、卡面或文字。

## 海湾地产局

- 2–4人在线地产经营；人数在创建房间时选择，所有玩家加入后自动开始。
- 40格环形棋盘，玩家掷两枚骰子移动；经过启航点领取2,000海贝。可购入22处分属8个街区的地产、4处铁路与2处公共设施。
- 落在无人地产时可按标价购买，也可发起轮流加价的公开竞拍；落在他人地产时自动收租。同色街区集齐后可均衡建造房屋并升级旅店，提升租金。
- 两类原创事件牌会移动玩家、收付海贝、触发维修费用或提供免罚通行券；棋盘还包含税费、免费休息区、探监与监所等空间。
- 玩家可在自己的行动阶段提出双向地产/海贝交易；可出售建筑、抵押地产筹款，并支付赎回费用解除抵押。无力清偿后宣布破产，地产转交债权人或回到公共市场；最后未破产的玩家获胜。
- 棋盘、城市、事件文案和视觉为原创设计，采用地产购买、租金、竞价与建设这类常见桌游机制，不使用《大富翁》名称、官方图形或卡牌原文。

双人实时领土经营策略游戏。玩家在风暴过后的群岛上采集资源、建造生产设施、争夺相邻土地，并竞逐公共项目与议会契约。客户端通过 WebSocket 与 Node.js 房间服务器同步状态。

## 核心规则

- 每局最多 16 轮，双方轮流行动；每位玩家在自己的回合只做 1 次行动。每轮双方各行动一次，且每轮换一位玩家先手。
- 五类行动牌（采集、建造、扩张、项目、议会）按个人顺序轮转。行动牌在序列中的位置决定强度；使用后移到队尾，因此要规划行动先后。
- 四种地形提供木材、石料、食物或知识。地块设施能在每轮生产资源；市场项目占用一块己方空地，提供即时奖励和持续效果。
- 项目市场为双方共享，买走后补入牌库下一张。议会契约也是共享竞逐目标，达成条件的玩家先领取奖励。
- 棋盘是半径 2 的 19 格六边形群岛；扩张按六向相邻关系判定，地形资源随地块固定。
- 三种即时获胜路线：控制 9 块领土、积累 12 点群岛影响力、达成 10 点生态复兴。若第 16 轮结束仍无人达成，则按影响力、生态、领土和建筑数计分。

行动详情及设施费用可在游戏中的“玩法说明”查看。

## 本地运行

```sh
npm install
npm start
```

运行规则测试：`npm test`

浏览器打开 `http://localhost:4173`。

## 公网部署（Render）

项目包含 `render.yaml`，用于创建 Render Node Web Service。将项目放进你自己的 GitHub 仓库（可设为 Private），然后在 Render 选择 **New → Blueprint** 并连接该仓库，按页面提示创建服务。部署完成后，把 Render 提供的 `https://…onrender.com` 地址发给玩家；页面会自动使用 WSS 建立实时连接。

当前房间和棋局状态保存在单个 Node 进程内存中。免费服务休眠、重新部署或进程重启时，进行中的房间会结束；免费实例也可能在空闲后休眠。该版本适合小范围试玩，不适合需要长期保留房间或高可用的正式运营。
