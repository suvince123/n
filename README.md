# 潮汐桌游社 · 在线桌游

双人在线桌游原型，目前包含《新岸宪章：群岛拓荒》和原创晶石经营游戏《星晶商路》。两个游戏共用房间号邀请与 WebSocket 房间服务。

## 星晶商路

- 玩家轮流进行单一行动：拿取晶石、购买市场发展卡、预留可见卡或盲抽卡。
- 三个等级的市场牌各有独立牌堆。发展卡提供永久颜色折扣和声望；预留卡最多三张，预留时可获得星砂。
- 永久折扣达到赞助人要求时自动获得其声望奖励。先达到 15 声望者触发最后一轮，对手再行动一次后结算。
- 五种颜色晶石与万能星砂共用储备；玩家库存上限为10枚。拿三种不同颜色，或在公用储备充足时拿两枚同色。
- 卡牌、名称与视觉均为本项目原创生成内容，不复用其他桌游的插画、卡面或文字。

双人实时领土经营策略游戏。玩家在风暴过后的群岛上采集资源、建造生产设施、争夺相邻土地，并竞逐公共项目与议会契约。客户端通过 WebSocket 与 Node.js 房间服务器同步状态。

## 核心规则

- 每局最多 16 轮，双方轮流行动；每位玩家在自己的回合只做 1 次行动。每轮双方各行动一次，且每轮换一位玩家先手。
- 五类行动牌（采集、建造、扩张、项目、议会）按个人顺序轮转。行动牌在序列中的位置决定强度；使用后移到队尾，因此要规划行动先后。
- 四种地形提供木材、石料、食物或知识。地块设施能在每轮生产资源；市场项目占用一块己方空地，提供即时奖励和持续效果。
- 项目市场为双方共享，买走后补入牌库下一张。议会契约也是共享竞逐目标，达成条件的玩家先领取奖励。
- 棋盘是半径 2 的 19 格六边形群岛；扩张按六向相邻关系判定，地形资源随地块固定。
- 三种即时获胜路线：控制 9 块领土、积累 12 点群岛影响力、达成 10 点生态复兴。若第 16 轮结束仍无人达成，则按影响力、生态、领土和建筑数计分。

行动详情及设施费用可在游戏中的“玩法说明”查看。

## 本地运行

```sh
npm install
npm start
```

浏览器打开 `http://localhost:4173`。

## 公网部署（Render）

项目包含 `render.yaml`，用于创建 Render Node Web Service。将项目放进你自己的 GitHub 仓库（可设为 Private），然后在 Render 选择 **New → Blueprint** 并连接该仓库，按页面提示创建服务。部署完成后，把 Render 提供的 `https://…onrender.com` 地址发给玩家；页面会自动使用 WSS 建立实时连接。

当前房间和棋局状态保存在单个 Node 进程内存中。免费服务休眠、重新部署或进程重启时，进行中的房间会结束；免费实例也可能在空闲后休眠。该版本适合小范围试玩，不适合需要长期保留房间或高可用的正式运营。
